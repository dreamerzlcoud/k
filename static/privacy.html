InkLab 데이터 보관 안내

InkLab은 PDF 편집과 개인 필기 적용을 위해 업로드한 PDF, 필기 샘플 이미지, 편집 배치와 생성 결과를 사용자별 비공개 저장소에 보관합니다. 다른 사용자에게 이 자료를 제공하지 않습니다.

ChatGPT에 연결하면 사용자가 허용한 MCP 도구를 통해 본인의 문서 텍스트, 페이지 이미지, 등록 글자 정보와 생성 결과를 ChatGPT가 읽을 수 있습니다. 공용 버전은 별도의 유료 OpenAI API 호출을 하지 않습니다.

파일은 Supabase 저장소에, 서버 처리는 Render에서 이루어집니다. 로그인과 OAuth 연결은 Supabase Auth가 처리합니다. MCP 권한은 ChatGPT에서 연결을 해제해 철회할 수 있습니다.

이 버전은 친구들과 시험 사용하는 비공개 베타입니다. 서버 운영자에게 저장 데이터 삭제를 요청할 수 있습니다. 공개 디렉터리 제출 전에는 운영 주체·문의처·보관 기간을 확정해 이 안내를 갱신해야 합니다.
