Codex에서 사용하기

프로젝트의 mcp-config.example.json 또는 codex-mcp.example.toml을 참고해 MCP 클라이언트에 등록하세요.

.venv/Scripts/python.exe -m inklab.mcp_server

작업 디렉터리는 이 프로젝트 폴더로 지정합니다. MCP를 호출하는 대화 모델이 풀이를 작성하므로, 이 방식에서는 InkLab에 별도 OpenAI API 키가 필요하지 않습니다.

“InkLab에 올린 과제를 읽고, 1번 풀이를 LaTeX로 배치해줘. 내 필기 프로필을 적용해 PDF로 만들어줘.”

브라우저에서 GPT 초안 생성

서버를 실행하기 전에 환경변수를 설정하세요. 키는 브라우저에 저장하지 않습니다. 

$env:OPENAI_API_KEY = "내 API 키"
$env:OPENAI_MODEL = "사용 가능한 모델 ID"
.\start.ps1

ChatGPT 웹 연결

현재 제공하는 것은 로컬 stdio MCP입니다. ChatGPT 웹에서 직접 연결하려면 인증을 갖춘 원격 HTTPS MCP 배포가 추가로 필요합니다. localhost 주소를 외부에 공개하는 구성은 포함하지 않습니다.
