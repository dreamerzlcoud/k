# 친구에게 전달할 InkLab 사용 안내

서버: https://inklab-shared.onrender.com

ChatGPT 연결 주소: https://inklab-shared.onrender.com/mcp

## 시작하기

1. 서버 주소를 열고 **GitHub 계정으로 로그인**합니다. 각자 계정의 PDF와 필기만 보입니다.
2. **PDF 가져오기**로 과제를 올립니다. **나의 필기체**에서 이미지나 PDF 샘플을 올리고 사용할 글자를 잘라 등록합니다.
3. ChatGPT의 플러그인 추가 메뉴에서 사용자 지정 MCP 서버 주소를 넣고 **OAuth**로 같은 InkLab 계정을 연결합니다. 이 메뉴의 제공 여부는 ChatGPT 계정·워크스페이스 정책에 따라 다릅니다.
4. 연결 후 이렇게 요청합니다: “InkLab에 올린 PDF를 확인하고, 빈칸에 풀이와 LaTeX 수식을 내 필기 프로필로 배치해줘. 완성된 페이지 이미지도 확인해줘.”
5. 완성 PDF를 확인한 뒤 내려받습니다. 학교 사이트 제출은 직접 진행합니다.

무료 서버가 쉬고 있으면 첫 접속에 약 1분 이상 걸릴 수 있습니다. 웹페이지를 먼저 열어 둔 뒤 ChatGPT 연결을 시도하세요. 서버 무료 한도와 ChatGPT 계정 사용 한도는 별개이며 무제한 서비스는 아닙니다.

현재 필기 기능은 등록한 글자 이미지로 수식·텍스트를 조합합니다. 사진 몇 장만으로 전체 필기체를 자동 학습하는 모델은 아직 아닙니다. 등록되지 않은 글자는 기본 모양으로 표시되고 목록으로 알려줍니다.

이 문서는 친구용 비공개 테스트 안내입니다. 공개 플러그인 디렉터리 심사와 출시는 완료되지 않았습니다.
